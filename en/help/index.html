How to read and listen

Reading on the site, downloadable books and tools in your browser.

1. Read on the site

Start with the complete works catalog for books, prose, poetry, articles and available translations.

The novel Pereborsh is available in Russian. Its landing page has a table of contents linking to the introduction and chapters. Within each chapter, the Russian links «Назад» (Back), «Оглавление» (Contents) and «Далее» (Next) take you through the book.

In a chapter, expand «Настройки чтения» (Reading settings) to enlarge the text or narrow the text column. The width option applies only on wide screens. «Сбросить настройки» (Reset settings) restores the original view. These controls are available when JavaScript is enabled.

2. Download a book

PDF keeps the book’s page layout. EPUB reflows the text to fit your screen and chosen font size.

The Schrödinger’s Cat on the Theory of Everything in a Patchwork Style landing page offers a PDF. The Pereborsh landing page offers both PDF and EPUB. Both books are in Russian; only Pereborsh has an EPUB edition.

Save the file to your device and open it in a suitable PDF or EPUB reader to read offline. Visiting a book’s landing page does not save the download.

3. Listen to the text

Your browser may be able to read the current page aloud. This does not translate it, and the site has no built-in audiobook. Voices, language support and commands depend on your browser, its version and your device. Some voices need an internet connection. Russian text needs a suitable Russian voice.

Open an article or an individual chapter. Move to the next chapter yourself, then start playback again.

Windows · Microsoft Edge, including PDFs

Open an article or chapter, then choose menu (…) → More tools → Read aloud. Some versions show Read aloud directly in the menu. You can also press Ctrl+Shift+U.

For a PDF, open the actual PDF file in Edge, using the link on the book’s landing page or a saved file. Choose Read aloud on the PDF toolbar rather than on the book’s description page.

For a passage, select the text, right-click and choose Read aloud selection if that command is available.

If playback stops after the first few words, try selecting the passage before restarting. A reader has tested this workaround. It is optional, and does not establish a cause or a universal defect.

Further help: Microsoft Edge accessibility.

Desktop · Google Chrome

Right-click the page → Open in reading mode → Play. Use this option where it is available for your page and browser version.

Further help: Chrome reading mode.

Android · Google Chrome

Choose menu (…) → Listen to this page. In the player, select Standard playback to hear all the words on the page. AI playback creates a conversation based on the page; an audio summary is not a word-for-word reading of the author’s text.

Google’s instructions require the Make searches and browsing better setting to be enabled. Availability varies with the page, language and Chrome version. If the menu item is missing, this method is currently unavailable.

Further help: Listen to this page in Chrome.

Mobile · Microsoft Edge

Look for Read aloud in the browser menu. Its exact location varies by version and device. If it is available, choose a suitable voice and reading speed.

iPhone · Safari

Open the page menu beside the address bar → Listen to Page, when available. This works with supported pages and languages; Russian-language playback is not guaranteed in every case.

Further help: listening to a page in Safari.

4. Add a site icon

For a quick way back, open the page you want and add its icon:

  • Android / Chrome: menu (…) → Add to Home screen.
  • iPhone / Safari: Share → Add to Home Screen.
  • Windows / Edge: menu (…) → More tools → Apps → Install this site as an app.

Confirm the addition or installation when prompted. Labels and menu locations may vary. An icon does not itself enable offline reading: download a book in advance and open it in a suitable reader.
