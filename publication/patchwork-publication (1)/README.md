# Английское издание для schrodingercat.org/en/book/

**Elena Berezina — Schrödinger’s Cat on a Theory of Everything, Patchwork-Style**

| Файл | Назначение |
|---|---|
| `assets/books/patchwork-en.pdf` | Английская книга, 165 страниц, кликабельное оглавление и закладки |
| `assets/books/patchwork-en.epub` | EPUB 3 с обложкой и навигацией по 82 текстам |
| `book-page.patch` | Изменения для `en/book/index.html` |
| `editorial/translation.en.md` | Редактируемый английский текст с привязкой к страницам оригинала |
| `editorial/source-pages.tsv` | Постраничная карта |
| `editorial/verification.md` | Сверка и редакционные решения |

## Как применить после утверждения

1. В рабочей копии сайта сохраните текущую `en/book/index.html` или убедитесь, что она отслеживается в Git и локальные изменения сохранены.
2. Из корня сайта проверьте `git apply --check <путь-к-патчу>/book-page.patch`. Если контекст страницы изменился, перенесите только изменения из патча после просмотра актуальной страницы.
3. Скопируйте оба английских файла из папки `assets/books` архива в одноимённую папку сайта и примените патч командой `git apply <путь-к-патчу>/book-page.patch`.
4. Локально откройте `/en/book/`. Проверьте обе новые ссылки, существующий переход на `/kniga/` и ссылку на русский PDF. Просмотрите `git diff` и `git status --short`.

Патч применён и проверен на отдельной копии английской страницы, использованной в начале работы. В рабочем репозитории выполните шаг 2.
